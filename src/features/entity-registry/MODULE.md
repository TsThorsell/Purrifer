# entity-registry

## Ansvar

`entity-registry` ager grundstrukturen for entiteter, aganderelationer och konton.

## Agda ytor

- entitetslista
- entitetsdetaljer
- relationer och andelar
- konton per entitet

## Tillatna beroenden

- shell-core layout
- sqlite via main-services
